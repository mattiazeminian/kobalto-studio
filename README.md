# Kobalto Studio

Sito Kobalto Studio in Next.js 15, App Router, React, TypeScript strict, Tailwind CSS e Motion.

## Avvio

Richiede Node.js 20.19 o superiore.

```bash
npm ci
npm run dev
```

Il sito sarà disponibile su `http://127.0.0.1:3000`.

## Verifiche

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

I testi, i progetti e i prezzi indicativi si modificano in `src/content/site.ts`. Il logo e le immagini sono in `public/assets`.

L'audit del sito di riferimento è in `docs/reference-audit.md`; le limitazioni della verifica visiva sono in `docs/validation.md`.
